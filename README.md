# Sneakers Rating Prediction

This is a Machine Learning based web application that predicts whether a sneaker will receive a high rating or not.

The prediction is based on features like:
- Brand
- Price
- Discount
- Number of Ratings

## Tech Stack Used
- Python
- Pandas
- Scikit-learn
- Flask
- HTML/CSS

## Project Workflow
1. Data Cleaning and Preprocessing
2. Label Encoding
3. Model Training
4. Model Saving using Pickle
5. Flask Web App Integration

## How to Run the Project

Step 1: Install dependencies
pip install -r requirements.txt

Step 2: Run the application
python app.py

Step 3: Open browser
http://127.0.0.1:5000

## Output
The user enters sneaker details and the model predicts whether it will be highly rated or not.
